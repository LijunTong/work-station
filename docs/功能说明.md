# 功能说明

README 只放界面示例与开发部署相关内容，这份文档记录具体功能。
内容按能力组织，不记开发进度。

## 项目

- 卡片列表，每张卡带进度环、任务统计、目标日期、优先级、颜色
- 新建与编辑抽屉；归档与取消归档
- 永久删除二次确认（级联删除其下任务）
- 项目看板：规划中 / 进行中 / 暂停 / 已完成四列，拖拽换列改状态；卡片可直接进入该项目筛选后的任务页

## 任务

- 日期分组：今日 / 逾期 / 本周 / 以后 / 无期限 / 已完结，分组可折叠
- 状态与项目筛选、关键字搜索
- 行内完成、编辑抽屉、删除确认
- 任务看板：待办 / 进行中 / 已阻塞 / 已完成 / 已逾期，拖拽换列即改状态并落库
  （已完成列默认只显示近 7 天，可一键放宽）

## 进度

- 自动模式：已完成 ÷（总数 − 已取消）
- 手动模式：直接取设定值

## 仪表盘

默认进入的首页。

- 今日 / 本周 / 本月三个口径的完成情况
- 需要立刻处理的事（逾期、已阻塞）排在最前
- 近 7 天到期与完成趋势
- 任务状态分布、优先级分布

## 提醒

- 三类：任务截止前（由任务表单的「提前提醒」自动排期）、每日站会（固定时间，一天一条）、手动新建
- 提醒页只有两组 —— 待办（已到点的排最前、带暖底）与已完成（默认收起，只留最近 20 条）
- 行内操作：完成 / 10 分钟后再提醒 / 删除
- 调度器 20 秒一拍，**先把状态写进库再弹通知**
- 重复规则（每天 / 每周）弹完自动排下一次；任务完成或取消时对应提醒自动作废
- 通知为窗口右下角的应用内通知；点提醒通知直接打开对应任务抽屉，点站会通知切到今日看板

## 快捷访问

- 全局快速添加：顶部常驻输入框，`n` 聚焦，任意页面回车即记一条
- 命令面板：`Ctrl+K` 搜任务、搜项目、跳页面、执行动作，全键盘操作
- 侧边栏徽标：全局逾期数
- 概览条：今日 / 逾期 / 已阻塞 / 本周 四个数字，点击即筛选；逾期、阻塞在有量时才染语义色
- 筛选：项目、优先级、关键字可与概览口径组合，一键清除

## 应用外壳

- **托盘常驻**：关窗口不退出，菜单「打开工作台 / 今日看板（逾期 N）/ 未处理提醒（N）/ 退出」；
  托盘建不出来的环境自动降级为关窗口即退出
- **单实例**：重复启动不再开第二个进程，只把已有窗口抬到前台
- **标签**：仓储与关联已实现，管理界面待做
- **周报月报与统计**：未开始

## 外观

- 明暗：浅色 / 深色 / 跟随系统，切换即时生效、重启保持
- 主题色：内置橙 / 红 / 绿 / 蓝四色之外，支持自定义主色与强调色（取色器 + 十六进制 + 实时预览）；
  明暗切换后自定义色不会被冲掉
- 字体：可从系统字体列表里挑一个，中文回退链保留（换西文字体不影响中文显示）
- 任务 / 项目 / 提醒三页的顶部操作区统一成卡片式工具栏

## 数据

- SQLite 单文件 + WAL
- 版本化迁移；启动时完整性检查；损坏自动留存重建
- 每日备份保留 7 份
- 数据库路径见 README「数据存放」
