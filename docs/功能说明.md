# 功能说明

> 按能力组织的现行功能清单，以及**唯一的完整快捷键表**。
> 事实源：`src/WorkStation.App/Views/`、`ViewModels/`、`src/WorkStation.Core/`。
> 数据存放见 [`README.md`](../README.md#数据存放)，界面规则见 [`设计系统.md`](设计系统.md)。

## 1. 页面与模块

**仪表盘**（默认首页）
今日 / 本周 / 本月三个口径的完成情况；需要立刻处理的事（逾期、已阻塞）排在最前；
近 7 天到期与完成趋势；任务状态分布、优先级分布。

**看板**
- 任务看板**四列**：待办 / 进行中 / 已阻塞 / 已完成。拖拽换列即改状态并落库；
  已完成列默认只显示近 7 天，可一键放宽。
- **逾期不是第五列**：它是顶部提示条 + 「只看逾期」视图。列代表工作流状态，拖进列等于改状态，
  而「把任务拖成逾期」定义不出动作。
- 项目看板四列：规划中 / 进行中 / 暂停 / 已完成；卡片可直接进入该项目筛选后的任务页。

**任务**
按日期分组（今日 / 逾期 / 本周 / 以后 / 无期限 / 已完结），分组可折叠；
状态与项目筛选、关键字搜索；行内完成、编辑抽屉、删除二次确认；
顶部快速添加在任意页面都能直接记一条。

**项目**
卡片带进度环、任务统计、目标日期、优先级、颜色；新建与编辑抽屉；归档与取消归档；
永久删除二次确认（级联删除其下任务）。进度自动模式 = 已完成 ÷（总数 − 已取消），
手动模式直接取设定值。

**提醒**
- 两类：任务截止前（由任务表单的「提前提醒」自动排期）、手动新建。
  另有三类**报告提醒**（日报 / 周报 / 月报），到点提示该写报告了。
- 页面只有两组：待办（已到点排最前、带暖底）与已完成（默认收起，只留最近 20 条）。
  行内操作：完成 / 10 分钟后再提醒 / 删除。
- 调度器 20 秒一拍，**先把状态写进库再发通知**；重复规则（每天 / 每周）弹完自动排下一次。
- 提醒是任务的派生数据：关掉提前提醒、清空截止时间、任务完成或取消，对应提醒都要作废，
  **包括已经弹过的那条**。

**报告**
- 日报 / 周报 / 月报三个周期，页内切换；每个周期自动生成一条，可回看旧周期。
- 左栏是**自动汇总**（按任务数据算出来的完成、未完成、逾期与统计数字），
  右栏是**人工补充**（自己写的）。
- 「重新汇总」只重算自动汇总，**人工补充一律保留** —— 周末补完的活不会把手写总结冲掉。
- 最终稿 = 自动汇总 + 人工补充，可**复制 Markdown** 或**导出 .md 文件**。

**命令面板**
`Ctrl+K` / `Ctrl+P` 打开或关闭，一个输入框同时承担搜任务、搜项目、跳页面、执行动作，
`↑` `↓` `Enter` `Esc` 全键盘操作。

**设置**
明暗三档（浅 / 深 / 跟随系统，切换即时生效、重启保持）；主题色（内置四色 + 自定义主色与强调色，
取色器 / 十六进制 / 实时预览，明暗切换不冲掉自定义值）；字体选择（中文回退链保留）；
日报 / 周报 / 月报提醒时间；数据目录；托盘开关。

## 2. 快捷访问

- 概览条：今日 / 逾期 / 已阻塞 / 本周，点击即筛选；逾期与阻塞在有量时才染语义色。
- 侧边栏徽标：全局逾期数，没有逾期时整个徽标隐藏。
- 筛选：项目、优先级、关键字可与概览口径组合，一键清除。
- 通知：窗口右下角的应用内通知，最多 3 条、10 秒消失。点任务提醒直接开那条任务的抽屉，
  点报告提醒通知切到报告页的对应周期。

## 3. 应用外壳

- **托盘常驻**：关窗口不退出，菜单只有「打开工作台 / 今日看板（逾期 N）/ 未处理提醒（N）/ 退出」。
  托盘建不出来的环境自动降级为关窗口即退出，并提示用户。
- **单实例**：重复启动不再开第二个进程，只把已有窗口抬到前台。
- **通知只在应用内**，不做系统 Toast：未打包的 exe 没有 AUMID，系统通知会静默失败。

## 4. 导航与快捷键

实现在 `src/WorkStation.App/Views/MainWindow.axaml.cs`。**焦点在输入框内时不响应单个字母与数字**，
避免打字时误跳页。

| 键 | 作用 |
| --- | --- |
| `1` – `7` | 依次切到 仪表盘 / 看板 / 任务 / 项目 / 提醒 / 报告 / 设置 |
| `Ctrl+1` – `Ctrl+7` | 同上（`Ctrl` 或 `Cmd` 均可） |
| `Ctrl+B` | 折叠 / 展开侧边栏 |
| `Ctrl+K` / `Ctrl+P` | 打开或关闭命令面板（同一个开关，再按一次即关闭） |
| `n` | 聚焦顶部快速添加框 |
| `/` | 聚焦当前页搜索框；页面没有搜索框时先跳到任务页再聚焦 |
| `Shift+/`（`?`） | 显示或隐藏快捷键说明 |
| `Ctrl+Enter` | 保存当前抽屉 |
| `Esc` | 关闭抽屉 / 浮层、关命令面板、关快捷键说明 |
| `↑` / `↓` / `Enter` | 命令面板内移动选中项 / 执行 |

## 6. 已知限制

- **Linux 安装包**（`.deb` 与绿色版 `tar.gz`）按 Debian 规范做过逐项格式自检，
  但**尚未在真机 Linux 上验证过安装、窗口显示与中文渲染**。
- **标签**：仓储与关联已实现，管理界面未做。
- **通知可见性**：窗口被完全收起时看不到应用内通知，只能靠托盘 tooltip 与侧边栏徽标。
