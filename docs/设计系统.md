# 工作台 · 设计系统

> 这份文档是界面的「宪法」：改界面前先在这里找对应的令牌或规则，不要临时写死颜色和间距。
> 令牌唯一实现在 `src/WorkStation.App/Styles/Tokens.axaml`，控件样式在 `Styles/App.axaml`。

## 1. 设计取向

用 UI/UX Pro Max 引擎按产品类型推导，匹配到 **Dashboard / Admin**（置信分 21.0），
推荐风格 **Data / Dashboard**（备选 Material、Industrial），配色口径是
「一个强调色 + 中性灰 + 语义状态色」。

引擎给出的默认调色板是红色系（Calm Analogous 001），那是它按 BM25 词面匹配的产物，
对一个任务管理工具不合适，已人工校正为蓝色单强调色方案。

落地三条原则：

1. **内容优先于容器** —— 描边和底色只用来分层，不用来装饰。列表行默认无边框，靠间距分组。
2. **一个强调色** —— 蓝色只出现在「当前在哪」「主操作」「进度」三处。其余靠灰阶拉开层次。
3. **红色是报警，不是装饰** —— 逾期、阻塞、删除确认才用红。列表里的删除按钮是灰色文字。

## 2. 色彩

浅色 / 深色各一套，全部走 `ThemeDictionary`，控件用 `DynamicResource` 引用。

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `BgBrush` | `#F5F6F9` | `#0E1116` | 页面底色（比分层面深一档，卡片才浮得起来） |
| `BgPanelBrush` | `#FFFFFF` | `#161A21` | 卡片、抽屉、侧边栏 |
| `BgSunkenBrush` | `#EDEFF4` | `#1C222C` | 内嵌区域、胶囊、分段控件底槽 |
| `BgHoverBrush` | `#F1F3F8` | `#1F2631` | 悬停 |
| `BgColumnBrush` | `#EAEDF4` | `#131820` | 看板列：浅色下比页面深、比卡片浅；深色下介于页面与卡片之间 |
| `LineBrush` | `#E4E7EE` | `#262D39` | 常规描边、分隔线 |
| `LineStrongBrush` | `#D3D8E2` | `#34404F` | 悬停描边、勾选框 |
| `TextBrush` | `#12161D` | `#E9ECF2` | 正文 |
| `TextSecondaryBrush` | `#3F4855` | `#C2CAD6` | 次级正文 |
| `TextDimBrush` | `#667085` | `#8B95A6` | 元信息（`.dim`） |
| `TextFaintBrush` | `#98A2B3` | `#5E6878` | 仅图标、箭头这类非文本元素 |
| `AccentBrush` | `#2F62E8` | `#6E97FF` | 主色 |
| `AccentSoftBrush` | `#EBF0FE` | `#18243D` | 选中底、激活导航 |
| `DangerBrush` | `#C0392F` | `#F0796F` | 逾期、删除 |
| `WarningBrush` | `#9A5B06` | `#E3A44A` | 警告 |
| `SuccessBrush` | `#0F7A57` | `#43C793` | 完成 |

**对比度口径**：`TextBrush` / `TextSecondaryBrush` / `TextDimBrush` 对各自背景均 ≥ 4.5:1；
`AccentBrush` 对白底 5.2:1，白字压其上同为 5.2:1。`TextFaintBrush` 达不到 4.5:1，
**只允许**用于装饰性图形，不得承载文字。

**项目色与优先级色**不走主题令牌，由视图模型直接给中间调 hex：同一份色值要同时在
白底和 `#161A21` 上看清，浅色系的语义色在深色主题会糊。

## 3. 字号阶梯

只有 6 档，新增字号先问「能不能复用已有的」。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `FontDisplay` | 22 | 页面标题（配 `TextBlock.page-title`，字距 -0.3） |
| `FontH2` | 16 | 抽屉标题、设置分组标题（`TextBlock.section-title`） |
| `FontBody` | 13.5 | 正文、输入框、列表标题 |
| `FontSm` | 12.5 | 按钮、表单标签、副标题 |
| `FontXs` | 11.5 | 元信息、路径、分组标题 |
| `FontMicro` | 10.5 | 胶囊文字、环内百分比 |

## 4. 间距与圆角

间距只用 4 的倍数：`4 / 6 / 8 / 12 / 16 / 20 / 24 / 28`。

- 页面左右内边距统一 `28`（`PagePadding`），标题区 `28,24,28,18`（`PageHeaderPadding`），
  各页工具栏一律 `28,0,28,16` —— 早先项目页误用了 `PageHeaderPadding`，标题和工具栏之间多出 24px 空白。
- 圆角：`RadiusSm 6`（胶囊、小按钮）/ `RadiusMd 9`（按钮、输入框）/ `RadiusLg 14`（卡片）/ `RadiusPill 999`。

## 5. 组件约定

### 按钮层级

| 场景 | 类 | 说明 |
| --- | --- | --- |
| 一屏唯一主操作 | `primary` | 强调色实底。`pointerover` 必须显式声明深一档，否则会被 Fluent 的默认悬停盖成灰底 |
| 危险操作 | `danger` | 实底红，**只出现在二次确认弹窗** |
| 列表行 / 卡片底部操作 | `ghost` | 无边框灰字，悬停才给底；破坏性操作加 `dangerish`，悬停才转红 |
| 图标按钮 | `icon` | 26×26 正方形 |
| 状态筛选 | `filter` | 胶囊，选中态 `active` = 淡蓝底 + 蓝边 + 蓝字 |

> 全局不要再写 `Button:pointerover /template/ ContentPresenter` 这类覆写：
> class 选择器比 Fluent 的类型选择器更特化，会把主按钮的悬停态也一并吃掉。

### 卡片

`Border.card` + 固定 `Width` 的 WrapPanel。卡片内部四段：标题行（含状态）、描述
（**固定 34px 高度**，否则长短不一导致底部对不齐）、进度行（42px 环 + 统计）、
操作行（上方 1px 分隔线，`Margin` 负值拉满整宽）。

### 任务行

列宽 `3,20,*,Auto,Auto`，列间距 10：

1. 3px 优先级色条（`Border.priority-bar`），无优先级则隐藏
2. 20px 完成圆钮（`Button.check`）
3. 标题 + 元信息（`MetaText` 由视图模型合成，不在 XAML 里拼分隔符）
4. 截止时间（逾期转红）
5. 行内操作，默认 `Opacity 0.5`，指针进入整行才恢复——否则每行都是「编辑 删除」，
   噪声盖过内容

**分组标题必须复用同一套列宽**（`3,20,*,Auto`），否则标题和任务标题的左边缘会差 27px。

### 顶部快速添加（合成框）

一行三段：`＋` / 输入框 / `详细新建`，容器 `Border.composer`（高 40）。

- **输入框必须显式 `VerticalContentAlignment="Center"`**（写在 `TextBox.bare` 里）。
  Avalonia 的 `TextPresenter` 默认会被 `MinHeight` 撑满整个输入框高度，而文字贴着行框顶部
  绘制，于是占位文字比同一行的按钮文字高 2.5px。加上之后行框缩到实际行高（18px）再居中，
  两者只差亚像素。
- **盒子中心对齐不等于文字对齐**：只比 `Bounds` 时三段的中心都是 20，看着「已经齐了」；
  必须比对渲染出来的像素行（占位文字 14–26、按钮文字 14–25 才算齐）。
  回归用例 `Composer_TextAndButtonShareOneCenterLine` 同时守中心线与行框高度两件事。

### 抽屉

`Grid` 三段：固定头部（标题 + ✕）、滚动内容、固定页脚（取消 / 保存）。
不再把按钮放在滚动区末尾——长表单里用户要滚到底才能保存。

### 看板

一屏四列（`UniformGrid Columns="4"`），列间距由每列右侧 `Margin 0,0,12,0` 提供，
因此页面内边距用 `BoardPadding`（`28,0,16,24`）——右侧少 12，最后一列的右缘才与标题、
搜索框齐平。

- **列**：`Border.column`（`BgColumnBrush` + 1px 描边 + `RadiusLg`）；拖拽悬停整列换成
  `AccentSoftBrush` + 蓝边，比在卡片上加虚线框更容易看清落点。
- **任务卡**：左侧 3px 优先级色条（复用 `Border.priority-bar`），标题两行封顶，
  下面「项目点 + 项目名」，最后一行元信息（截止 / 预估 / 优先级）合成一个字符串。
  标题用 `FontBody`：它是一屏的主内容，不能按次级字号处理。
- **项目卡**：名称 + 色点、描述两行、38px 进度环 + 统计、`进入任务看板 →` 文字链接。
  统计只写「N 个任务」——列最窄到 170 出头，再加「进行中 N」会被裁成半句。
- **概览条**：`Button.stat`（数字 15px 半粗 + 标签 12.5px 灰字），选中态淡蓝底 + 蓝边；
  逾期、已阻塞在数字非零时才染语义色，其余保持正文色，否则每个数字都在喊。
- **已完成列**默认只留近 7 天，列头右侧放一个 `ghost sm` 按钮在「显示全部 / 只看近 7 天」间切换。

### 命令面板与徽标

- 面板 `Border.palette`：580 宽、距顶 88、`RadiusLg` + 大阴影，遮罩用 `ScrimBrush`。
- 结果行是 `Button.palette-row`（透明底、`RadiusSm`、选中态 `AccentSoftBrush`），
  左侧 26px 方形字形块 + 标题 + 右侧灰色来源标签（跳转 / 动作 / 帮助 / 项目 / 任务）。
- 侧边栏徽标 `Border.badge`：`DangerSoftBrush` 底 + `DangerBrush` 字，只挂在「看板」上，
  数字是全局逾期数；没有逾期时整个徽标隐藏，不留一个「0」占位。
- 快捷键说明里的按键用 `TextBlock.key`（等宽字体 + `FontXs`），靠字体而不是色块区分。

## 6. 已知取舍

- **状态用圆点 + 文字，不用色块胶囊**：白卡上的浅灰底几乎不可见，反而像文字溢出了底色。
- **进度环颜色跟随项目色，无项目色时回落强调色**：早先直接绑 `AccentBrush`，
  无色的项目会解析成 `Transparent`，整个环直接消失。
- **深色主题下强调色提亮**（`#6E97FF`）：沿用浅色值会在深底上糊成一团。
- **看板不做横向滚动**：把 `UniformGrid` 放进横向 `ScrollViewer` 时，测量阶段拿到的是无限宽度，
  单元格会按最长文本撑开，四列直接溢出并被裁掉。改成四列等分自适应后，1024 最小宽度下
  每列约 175px，卡片标题最多两行——这是「一屏看全」换取的空间代价，比切掉半列更可接受。
- **视图模型里取主题画刷必须带 `ActualThemeVariant`**：`TryGetResource(key, null, …)` 会落到
  默认（浅色）字典，深色界面上概览数字会取到近黑色，等于看不见。统一走 `ThemeBrushes.Get`。

## 7. 复查方式

可视化验证靠无头宿主做真实光栅化（`TestAppBuilder` 里 `UseHeadlessDrawing = false` + `UseSkia`），
把 `MainWindow` 直接渲染成 PNG 逐张核对。需要复核时临时写一个截图用例即可，**不要提交**——
它依赖固定的种子数据，不适合当回归测试。
