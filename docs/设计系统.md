# 设计系统

> 界面的现行规范。事实源是 `src/WorkStation.App/App.axaml` 与 `Views/*.axaml`。
> 改界面前读这份；改完代码要同步这份。不可违背的硬约束见根目录 [`AGENT.md`](../AGENT.md)。
> 截图来自 `Avalonia.Headless` 真实渲染，流程见 [README「测试与截图流程」](../README.md#测试与截图流程)。

## 1. 设计取向

1. **内容优先于容器** —— 描边和底色只用来分层，不用来装饰。列表行默认无边框，靠间距分组。
2. **一个强调色** —— 强调色只出现在「当前在哪」「主操作」「进度」三处，其余靠灰阶拉开层次。
3. **红色是报警，不是装饰** —— 逾期、阻塞、删除确认才用红；列表里的删除按钮是灰色文字。
4. **外观交给 SukiUI** —— 颜色用 Suki 主题键，控件用 Suki 的样式类与控件。本项目只定义「尺寸」与「材质」：SukiUI 自带卡片底色不透明，铺满一屏就是一叠白盒子，所以额外定义了半透明面板色，让背景渐变能透上来。

项目色与优先级色不走主题键，由视图模型直接给中间调 hex：同一份色值要同时在明暗两套底上看清，浅色系语义色在深色主题会糊。深色主题下强调色需提亮。

## 2. 对比度与可读性

- 正文、次级正文、元信息对各自背景均需 ≥ 4.5:1；低对比色**只允许**用于装饰性图形，不得承载文字。
- 图标按钮必须有 `ToolTip.Tip`：图标不承载文字，没有提示就等于一个匿名控件。
- 输入框的值文字比正文大半档，占位文字用 `TextDim` 一档的灰但保持可读；Fluent 默认的浅灰占位太淡。
- 中文字形必须显式指定。`Program.cs` 的 `FontManagerOptions` 是无指定时的兜底，中文回退链必须保留。

## 3. 基础令牌（按 `App.axaml` 现状）

全部定义在 `App.axaml` 的 `Application.Resources`，**不另建令牌或样式文件**；新增字号/圆角先问「能不能复用已有的」。

### 字号（8 档）

| 键 | 值 | 用途 |
| --- | --- | --- |
| `FontSizeDisplay` | 34 | 仪表盘主数字（全站最大，只此一处） |
| `FontSizeMetric` | 24 | 圆环内的大百分比 |
| `FontSizeTitle` | 22 | 页面标题 |
| `FontSizeHeading` | 16 | 卡片/区块标题、弹框标题 |
| `FontSizeSubhead` | 14 | 分组标题、圆环内百分比 |
| `FontSizeBody` | 13 | 正文、任务标题、列表项、按钮与输入控件 |
| `FontSizeCaption` | 12 | 说明文字、字段标签、元信息 |
| `FontSizeMicro` | 11 | 角标数字、图例、计数徽标 |

交互控件（`Button` / `TextBox` / `ComboBox` / `ToggleButton`）统一压到 `FontSizeBody`：控件文字与正文同档，靠颜色和字重分主次，不靠字号。

### 圆角（按层级，不按控件高度）

| 键 | 值 | 用在哪 |
| --- | --- | --- |
| `CardCornerRadius` | 20 | 块级卡片：图表面板、项目卡片 |
| `CardRowCornerRadius` | 10 | 列表行：任务行、提醒行 |
| `CardContainerCornerRadius` | 24 | 页面级容器：页面头、看板列 |

同一行里的控件圆角一致，容器之间靠「内层比外层小一档」表达嵌套。

### 页面留白

| 键 | 值 | 用在哪 |
| --- | --- | --- |
| `PageGutter` | `24,0,24,0` | 所有页面内容区左右统一 24 |
| `PageGutterBottom` | `24,0,24,24` | 内容区底部 |
| `PageHeaderMargin` | `24,12,24,16` | 页面头：上 12 不贴标题栏，下 16 与工具栏分开 |
| `PageGutterBelowHeader` | `24,0,24,16` | 页面头下面第一块（工具栏卡） |

### 材质与颜色

`ThemeDictionaries` 里 Light / Dark 各一套半透明材质：

- `SurfaceGlass`（卡片底）、`SurfaceGlassRaised`（页面头、弹窗，更实）、`SurfaceGlassSunken`（内嵌区域）
- `SurfaceStroke` / `SurfaceStrokeSoft`（发丝描边）、`SurfaceHover`、`SurfaceDivider`
- `SurfaceWarning` / `SurfaceAttention` / `SurfaceDanger`（已到点提醒、逾期提示条、危险标签的底）

文字与语义色一律取 Suki 主题键：`SukiText`、`SukiMuteText`、`SukiDangerColor` 等。视图模型里取主题画刷必须带 `ActualThemeVariant`，否则会落到默认（浅色）字典，深色界面上文字等于看不见。

## 4. 控件与组件

| 场景 | 用什么 | 约定 |
| --- | --- | --- |
| 卡片 / 页面头 / 看板列 | `suki:GlassCard` | 样式类 `card` / `header-card` / `column` / `board-card`；关掉 `IsAnimated`，避免液态渐变叠在半透明底上发灰 |
| 列表行 | `Border.card-row` | 透明底 + 底部 1px 发丝线分隔；`done` 变淡、`alert` 加警示底。变体规则必须和基础规则写在同一个样式集合里，分开放会被更具体的选择器整条遮蔽 |
| 进度环 | `suki:CircleProgressBar` | 不自绘，保证线宽/端点/起始角与旁边控件同体系；无项目色时回落强调色，不能解析成透明 |
| 图标 | `PathIcon` + `Controls/AppIcons.cs` | 静态 `StreamGeometry` 表；颜色靠 `Foreground` 继承，单独摆放才显式给色。新增图标改这张表，不要在 XAML 里手画 Canvas |
| 弹框 / 抽屉 / 命令面板 | `SukiDialog` | 命令面板的 ↑/↓/Enter/Esc 由窗口统一分发（焦点不一定在弹框控件树上） |
| 日期与时间 | `CalendarDatePicker` | 与输入框同高；只给日期时补默认时刻 |
| 主操作 | `Classes="Basic"` | 一屏只放一个实底主操作 |
| 危险操作 | `Button.danger` | 静止与普通图标一致，悬停才转红 |
| 取色器 | `Themes/SukiColorPicker.axaml` | 必须排在 Fluent 版 `ColorPicker` 样式**之后**，控件主题按「后加入覆盖先加入」解析 |

**字体**：设置页换字体要同时改 `DefaultFontFamily`（正文控件）与 `UiFontFamily`（窗口级浮层：弹窗、下拉、ToolTip 不继承 Suki 的选择器），只改一个会有一半界面不跟随。

### 仍成立的行为取舍

- **行内操作只给图标**：文字按钮在列表里占一整段宽度，还会和正文同字号、看起来像可点的词；代价是首次使用靠 tooltip 认，所以图标按钮强制带提示。
- **对话框的「取消 / 保存」保留文字**：图标化后「取消」只能画成叉，与右上角关闭撞车。
- **状态用视觉表达，不占分组和标签**：提醒页只有「待办 / 已完成」两组，已完成默认收起（它是存档不是待办）；已到点的排最前、带暖底和琥珀竖条，混在待办组里而不是单开一组。
- **提醒页不做筛选、没有「忽略」**：三类提醒合起来通常十几条，加筛选栏会把它变成第二个任务页；「忽略」和「完成」对用户是同一种结果。定位具体某条用 `Ctrl+K`。
- **通知走应用内 `WindowNotificationManager`**：系统 Toast 需要 AUMID 与打包身份，未打包的 exe 上会静默失败 —— 表现为「设了提醒却没反应」，比没有通知更糟。代价是窗口完全收起时看不到，只能靠托盘 tooltip 与徽标。
- **托盘菜单只四项**：托盘不是第二个应用；塞满导航项会让人在两层导航之间犹豫。托盘建不出来时安静降级为关窗口即退出，**并且要提示用户**，否则用户分不清是系统不支持还是没找到图标。图标读不出来就不要建托盘，宁可没有也不要留一个看不见的图标。
- **每个设置开关都要写「关掉会怎样」**：只写开关名，用户得先试一遍才知道后果。
- **看板逾期做成视图，不做成列**：列是工作流状态，拖进列等于改状态；逾期是时间属性，同一张卡会同时属于「待办」和「已逾期」，而「拖成逾期」定义不出动作。顶部提示条 + 「只看逾期」筛选即可。
- **看板列设最小宽度，窄窗时横向滚动**：四列等分自适应会把卡片挤到标题被裁，滚动比切掉半列可接受。
- **设置不进主导航**：它是低频入口，占一格会稀释「看板 / 任务 / 项目」这条主线；收在侧边栏左下角。

## 5. 页面布局

任务 / 项目 / 提醒三页共用同一套卡片式工具栏：`Border Classes="card"` + `PageGutterBelowHeader`。新页面照抄，不要自己写一套内边距。

页面头是浮在标题栏下的第一块，用 `PageHeaderMargin`；它下面第一块只需 `PageGutterBelowHeader`（上方 16 已由页面头的下边距给过）。两张同色圆角卡严丝合缝拼在一起，会看起来像一张卡被切了一刀。

看板列本身有 12px 内距，列内卡片再留 20 会显得松，用 `board-card` 样式收一档。

## 6. 维护约定

- 改 `App.axaml` 的令牌、控件样式或主题材质 → 同步本文 §3 / §4 与 [`AGENT.md`](../AGENT.md) 的 UI 硬规则。
- 改主题、控件样式或排版后：跑 `dotnet test` → 跑 `VisualCheck` → 肉眼看 `.shots/` 里浅/深两套 → 必要时同步 `docs/images/`（流程见 README）。`VisualCheck.cs` 是已提交的截图回归，**不要删**。
- 需要临时复核时另写一次性截图用例，别把固定种子数据的用例混进回归集。
