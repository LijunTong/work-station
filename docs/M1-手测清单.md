# M1 手测清单

打包后执行，逐项打勾。启动：`dist/win-x64/WorkStation.exe`；开发期可先 `dotnet run --project src/WorkStation.App`。

## 启动与数据持久化

- [ ] 双击 exe，窗口正常打开（本地 SSD 冷启动 ≤ 3 秒）
- [ ] 侧边栏「项目 / 任务 / 设置」可切换，右上标题随之变化，选中项高亮
- [ ] 新建项目 → 关闭 exe → 重新打开，项目仍在
- [ ] 打包版数据库位于 `%APPDATA%\work-station\data.db`；开发期在仓库 `.data/data.db`
- [ ] exe 为单文件，目标机只装 .NET 10 运行时即可运行

## 项目

- [ ] 新建项目：名称、描述、状态、优先级、起止日期、进度模式均可填写并保存
- [ ] 名称为空时保存，抽屉内显示「项目名称不能为空」，不落库
- [ ] 日期写成 `2026/12/01` 时提示「格式应为 YYYY-MM-DD」
- [ ] 目标日期早于开始日期时提示「目标日期不能早于开始日期」
- [ ] 编辑项目只改名称，描述与优先级保持不变
- [ ] 勾选「显示已归档」后能看到归档项目；点「取消归档」后回到默认列表
- [ ] 删除项目弹出二次确认，确认后项目与其任务一并消失（不可恢复）
- [ ] 进度环：自动模式随任务完成比例变化；手动模式使用设定值
- [ ] 卡片显示任务总数、进行中数、逾期数（逾期为红色）与目标日期

## 任务

- [ ] 快速添加条输入后回车，任务出现在「无期限」组
- [ ] 详细新建可选择所属项目，也可留为「独立任务」
- [ ] 已归档项目不出现在任务表单的项目下拉中（筛选下拉仍可见，标「（已归档）」）
- [ ] 截止时间填 `2026-11-06`（只填日期）保存后为当天 18:00
- [ ] 截止时间写成「明天下午」时提示格式错误，不落库
- [ ] 过期未完成的任务进「逾期」组，时间标红
- [ ] 点击分组标题（今日/逾期/本周/以后/无期限/已完结）可折叠，再点展开；折叠状态在刷新后保持
- [ ] 点行首圆圈完成任务 → 移入「已完结」并灰显，圆圈不再可点
- [ ] 状态为「已阻塞」时抽屉出现阻塞原因输入框
- [ ] 状态与项目下拉可筛选；搜索框按标题与备注过滤
- [ ] 筛选无结果时显示「没有符合条件的任务」与「清除筛选」，不会与错误提示同屏
- [ ] 抽屉内 `Esc` 关闭且不保存草稿，`Ctrl+Enter` 保存
- [ ] 删除任务需二次确认

## 主题

- [ ] 设置页切换浅色 / 深色 / 跟随系统，界面立即变化（无需重启）
- [ ] 关闭并重开 exe，主题保持上次选择
- [ ] 深色主题下侧边栏、卡片、抽屉、输入框文字均清晰可读

## 异常

- [ ] 断网状态下全部功能正常（应用无任何网络调用）
- [ ] 删除 `data.db` 后重启，程序重建空库、正常打开
- [ ] 把 `data.db` 内容改成乱码后重启：界面提示「数据库已损坏，已重建空库」，同目录留下 `data.db.corrupt-<日期>`，且能继续新建数据
- [ ] `backups/` 目录中生成 `data-<日期>.db`，且不超过 7 份
- [ ] 数据库文件被其他进程独占时启动：窗口显示「无法启动工作台」与原因，不闪退

## 已知限制（M1 不做）

- 看板与拖拽改状态、命令面板、快捷键 `n` / `/` / `Ctrl+K`（M2）
- 按优先级与标签筛选（M2，标签管理界面同期做）
- 托盘常驻、系统通知、提醒调度（M3）
- 周报月报、统计页（M4）
