# M3 手测清单

打包后执行，逐项打勾。启动：`dist/win-x64/WorkStation.exe`；开发期可先 `dotnet run --project src/WorkStation.App`。

> **先造数据**：提醒类验收依赖「已到点」的记录，库里没有就只能空等。最快的造数方式在最后一节
> 「造数步骤」，建议先照做一遍再从上往下勾。上一轮 M2 清单里有一半项勾不上，就是因为缺对应数据。

## 任务截止提醒（自动排期）

- [ ] 新建任务，设截止时间「今天 18:00」。「提前提醒」下拉默认「不提醒」，此时提醒页里没有这条
- [ ] 把「提前提醒」改成「提前 1 小时」并保存 → 提醒页「待触发」出现一条，时间为 17:00
- [ ] 同一任务再改成「提前 1 天」→ 仍是**一条**（不是两条），时间变为昨天 18:00 且立刻进入「待处理」
- [ ] 把截止时间清掉（日历浮层里的 ✕）→ 该提醒从提醒页消失
- [ ] 截止时间存在、但「提前提醒」选「不提醒」→ 提醒页无记录（0 分钟不等于到点提醒）
- [ ] 任务标记完成后，其待触发提醒自动消失，不会在到点时再弹
- [ ] 任务改为「已取消」同样不弹；改回「待办」并保留截止时间 → 提醒重新排上
- [ ] 提醒页里这条任务的标题跟随任务当前标题：改任务标题后提醒页同步（不用重启）

## 提醒页

- [ ] 侧边栏「提醒」项有数字徽标，数字 = 待处理条数；清零后徽标整体隐藏
- [ ] 三组顺序为 待处理 → 待触发 → 已处理；某组为空时整组隐藏，不留「0 条」空壳
- [ ] 「待处理」行是暖色底 + 左侧琥珀竖条，「待触发」是普通白底，扫一眼能分开
- [ ] 时间显示为「今天 17:00 / 明天 09:00 / 昨天 14:00 / 周三 10:00」这类相对口径，跨年才带年份
- [ ] 逾期的提醒时间显示为琥珀色
- [ ] 每行右侧状态 chip 与动作图标：待处理有 勾 / 钟 / 叉 / 垃圾桶；待触发只有 勾 / 叉 / 垃圾桶；
      已处理只剩垃圾桶
- [ ] 点「勾」→ 该行移到「已处理」；点「叉」（忽略）→ 同样进「已处理」
- [ ] 点「钟」→ 时间变为当前 +10 分钟，行回到「待触发」
- [ ] 点垃圾桶 → 出现删除确认，确认后行消失；取消则不动
- [ ] 「已处理」组最多 20 条，更早的被截掉
- [ ] 点「新建提醒」→ 抽屉展开，默认时间是「半小时后的整 5 分钟」；只填标题即可保存
- [ ] 抽屉里时间留空保存 → 提示必填，不写入库
- [ ] 重复选「每天」→ 弹过一次后自动排到次日同一时刻，仍留在「待触发」，不进入「已处理」
- [ ] 重复选「每周」同理顺延 7 天
- [ ] 深色主题下三组行、状态 chip、动作图标全部清晰可读，暖底行不发黑

## 通知与跳转

- [ ] 到点后窗口**右下角**弹出通知：标题是「任务提醒」或「提醒」，正文是内容（任务类为
      `标题 · 项目名 · 截止 11月6日 18:00`）
- [ ] 同时到点多条时最多同时显示 3 条，10 秒后自动消失，不叠成一片
- [ ] 点任务类通知 → 窗口前置并打开该任务的编辑抽屉
- [ ] 关掉通知不点（等它自己消失）→ 提醒转入「待处理」，状态不丢
- [ ] 应用完全退出期间到点的提醒，下次启动后立刻进入「待处理」并补弹一次（不重复弹第二次）

## 每日站会提醒

- [ ] 设置 → 提醒 →「每日站会提醒」默认开启，时间默认 09:00
- [ ] 把时间改成「当前时间的下一分钟」→ 到点弹一条，标题「今日站会」，正文
      `昨日完成 N 项 · 逾期 N 项 · 今晚到期 N 项`
- [ ] 点站会通知 → 跳到看板并切到「今日」口径（概览条「今日」高亮）
- [ ] 当天只弹一次：再等一拍不会重复弹（`settings.daily_review_last` 去重）
- [ ] 关掉开关 → 当天不再弹；重新打开 → 次日恢复
- [ ] 站会时间下拉包含 06:00–22:00 的半点，拖到底能看到 22:00

## 托盘与窗口行为

- [ ] 标题栏关闭按钮（✕）→ 窗口消失但进程仍在，托盘图标还在
- [ ] 托盘图标 tooltip 显示「工作台 · N 条提醒待处理 · N 条逾期」
- [ ] 托盘右键菜单四项：打开工作台 / 今日看板（逾期 N）/ 未处理提醒（N）/ 退出
- [ ] 「今日看板」→ 窗口回来并切到看板今日口径；「未处理提醒」→ 切到提醒页
- [ ] 无待处理提醒时「未处理提醒」菜单项为禁用态，标题不带「（0）」
- [ ] 左键单击托盘图标 → 窗口回来
- [ ] 托盘菜单「退出」→ 进程真正结束（任务管理器里没有 WorkStation.exe）
- [ ] 窗口最小化到任务栏后，提醒照常弹（通知不依赖窗口可见）
- [ ] 设置里关掉「关闭窗口时驻留托盘」→ 点 ✕ 直接退出进程

- [ ] 已有窗口最小化 / 隐藏到托盘时再启动 → 窗口恢复并前置
- [ ] 用两个不同用户账户同时运行不受影响（命名对象按会话隔离）

- [ ] M1、M2 清单中的项目、任务、看板、拖拽、命令面板、主题项仍全部通过
- [ ] 命令面板里能搜到「提醒」跳转与「新建提醒」动作

## 造数步骤

提醒时间只能精确到分钟，所以「等它到点」最省事的做法是把时间设成**当前这一分钟或更早**：

1. 进「提醒」页 →「新建提醒」→ 标题随便写 `测试 · 到点` → 时间选「今天」，时刻填当前时间的时:分
   → 保存。**20 秒内**就会弹通知并进入「待处理」（`remind_at <= now` 即视为到点，不需要真的等）。
2. 想看「先待触发、再到点」的完整过程：时间填**下一分钟**，保存后回看板页干等 20–80 秒
   （调度器 20 秒一拍）。
3. 要造「重复提醒」：新建时重复选「每天」，时间设为当前分钟 → 弹一次后自动跳到明天同一时刻，
   能在「待触发」里看到它挪走了。
4. 要造「任务截止提醒」：任务页新建任务，截止时间设为「今天 + 当前时间之后 1 小时」，
   提前提醒选「提前 1 小时」→ 提醒时间就是当前分钟，一拍后即弹。
5. 站会提醒：设置里把站会时间设为下一分钟，等一拍即可；测完记得改回 09:00。
6. 要造「已处理的旧记录」直接在提醒页把几条点成「勾」或「叉」——「已处理」组只留最近 20 条，
   想看截断效果得攒 21 条。

> 想直接改库造数也可以（`%APPDATA%\work-station\data.db`，`reminders` 表，`remind_at` 格式
> `yyyy-MM-ddTHH:mm` 本地墙钟），但**必须先退出应用**——运行中改库会被启动时的
> `RemindersSync()` 覆盖回任务截止时间算出来的值。
